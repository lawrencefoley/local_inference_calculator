# Local Inference Calculator

Capacity planning tool for local LLM inference.

Ferramenta de capacity planning para inferência local de LLMs.

Quickly discover which language models run on your GPU for a given context size.

Descubra rapidamente quais modelos de linguagem rodam na sua GPU para um determinado tamanho de contexto.

## Installation / Instalação

```bash
cd local_inference_calculator
```

No external dependencies beyond Python standard library.

Não há dependências externas além da Python standard library.

## Usage / Uso

### Basic / Básico

```bash
python main.py --context 4096
```

### Consumer GPUs only / Apenas GPUs consumer

```bash
python main.py -c 8192 --gpu-type consumer
```

### Show only viable combinations / Mostrar apenas combinações viáveis

```bash
python main.py -c 4096 --only-runs
```

### Export results / Exportar resultados

```bash
python main.py -c 4096 --export-json results.json
python main.py -c 4096 --export-csv results.csv
```

## VRAM Calculation / Cálculo de VRAM

The tool uses a conservative estimation model:

A ferramenta usa um modelo conservador de estimativa:

1. **Model Parameters**: `params_billion × bytes_per_param`
   **Parâmetros do modelo**: `params_billion × bytes_per_param`

2. **Overhead**: `+30%` (runtime, activations)
   **Overhead**: `+30%` (runtime, activations)

3. **KV Cache**: `(kv_cache_mb_per_token × context_tokens × multiplier) / 1024`

Bytes per parameter by precision:
Bytes por parâmetro por precisão:

- FP32: 4 bytes
- FP16: 2 bytes (default / padrão)
- INT8: 1 byte
- INT4: 0.5 byte
